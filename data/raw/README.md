# Raw Data

Store source data here exactly as obtained. Do not manually correct, rename columns within, or overwrite an original file.

For every file, record:

- public source URL;
- publisher;
- date accessed;
- reporting period;
- file format;
- data grain;
- known filters, exclusions and caveats; and
- any licence or reuse statement.

If data must be copied from an interactive public visual rather than downloaded, document the extraction steps and retain a dated source screenshot where permitted.
