# Future-state design

## Purpose

This section presents a proposed complaint-management operating model focused on visibility, consistency, fairness, security and auditable human decision-making.

The design responds to the public-data analysis and current-state discovery hypotheses. It is a case-study proposal rather than an approved AFCA design.

## Design approach

The proposed future state:

- retains human accountability for material decisions;
- makes triage, priority and allocation explainable;
- provides clear ownership and next-action visibility;
- records overrides and material actions;
- protects sensitive complaint information;
- supports accessibility and appropriate exceptions;
- improves monitoring of workload and overdue work; and
- separates validated requirements from assumptions.

All detailed rules, roles, thresholds and service targets require stakeholder validation.
