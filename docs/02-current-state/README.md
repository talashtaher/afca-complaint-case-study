# Current-state analysis

## Purpose

This section documents the complaint-management environment using AFCA public information and clearly labelled case-study assumptions.

It does not claim access to AFCA’s internal processes, systems or organisational structure.

## Artefacts

- [Preliminary stakeholder map](stakeholder-map.md)
- [Complaint-process context diagram](context-diagram.md)
- [Public complaint-process map](public-process-map.md)
- [Preliminary pain-point and risk register](pain-point-register.md)

## Analysis approach

The current-state analysis separates:

- information supported by AFCA public sources;
- operational risks inferred from the published process; and
- hypotheses requiring stakeholder or internal-data validation.

Unconfirmed assumptions are recorded as discovery questions rather than presented as facts.
