# Dashboard

The Power BI dashboard will be designed after the data grain, definitions and limitations have been confirmed.

Planned questions include:

- How has complaint demand changed over time?
- How do complaints received, progressed and resolved compare?
- Which products, issues or financial-firm categories account for the greatest complaint volume?
- Where are changes material rather than merely visually noticeable?
- Which measures would help an operations manager monitor demand and flow?

The final dashboard folder will include the `.pbix` file, KPI definitions, screenshots and a short usage guide.
